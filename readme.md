# 📝 Aplicação de Posts - Simulação de Rede Social
📋 Descrição
Uma aplicação web para criar e publicar posts em uma API simulada, similar a funcionalidades de redes sociais como Facebook e LinkedIn.

# 🚀 Funcionalidades
✅ Criar posts com título e conteúdo

✅ Envio dos dados para API REST (JSONPlaceholder)

✅ Exibição dos posts publicados

✅ Contador de caracteres em tempo real

✅ Modal de confirmação após publicação

✅ Design responsivo e moderno

✅ Validação de formulário

# 🛠️ Tecnologias
HTML5
CSS3 (Flexbox, Grid, Variáveis CSS)
JavaScript ES6+ (Fetch API, async/await)
Font Awesome (ícones)
Google Fonts

# 🔧 Como Usar
Clone o repositório

Abra o arquivo index.html em um navegador

Preencha o título e conteúdo do post

Clique em "Publicar Post"

Veja seu post aparecer na lista

# 🌐 API Utilizada
URL: https://jsonplaceholder.typicode.com/posts

Método: POST

Headers: Content-type: application/json

Corpo da requisição:

json
{
  "title": "string",
  "body": "string", 
  "userId": 1
}
